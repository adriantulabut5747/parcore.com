Common questions

Quick answers before you dive in.

Is Parchrome free?

Yes. Every page is free, and you never need an account to use it.

How do I copy a base layout into Clash of Clans?

Open your Town Hall's layouts page and tap Copy layout on the base you want. The link opens Clash of Clans and offers to save the base, so open it on the device the game is installed on. Army comps work the same way.

How often are layouts and guides updated?

New bases and guides go up as the games update. Fresh bases carry a red NEW tag on their page, and the banner above the game rows tells you when a Town Hall gets new ones.

Are the websites in Web Resources safe?

Every site is checked before it goes on the list, but free sites can still run heavy ads and pop-ups. Use an ad blocker such as uBlock Origin, and never download a file you did not ask for.

Can I suggest a game, guide or website?

Yes. Use the feedback form on this page for guides and games. To suggest a website, use the Contribute page in Web Resources.

Why isn't my game on Parchrome yet?

A game gets its own page once there is enough solid content for it. The Coming soon cards under Featured Games show which games are next.
