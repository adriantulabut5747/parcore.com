    Ask Klee.

    KleeKlee keeps her shiniest artifacts in her backpack! Tell Klee what else you want to know.

    When are artifact domains open?

    Every day. Unlike talent and weapon materials, artifact domains have no day schedule, so farm the set you need whenever you like.

    Is “Best for” the only right pick?

    No. It lists characters the set is a common pick for, not the only right answer: the best set changes with your team and the rest of your build.

    What does the Rarity filter mean?

    The highest rarity a set comes in. Only 5★ sets reach the best main stats, so the lower ones are mostly for the early game.

    When do new sets show up?

    The list is checked for new sets every three hours from Project Amber. Where each set drops comes from the Genshin Impact Wiki.
