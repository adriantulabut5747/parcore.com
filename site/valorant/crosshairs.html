Put it in your game

JettThree steps and it's in your game. Faster than my dash? Nothing is, but this comes close.

  1. Press Copy code under the maker, or Copy on any starter or saved crosshair.
  2. In Valorant, open Settings, go to the Crosshair tab and pick the profile you want to replace.
  3. Press Import Profile Code next to the profile name, paste the code and import it. A pasted pro code keeps its ADS and Sniper parts too.
