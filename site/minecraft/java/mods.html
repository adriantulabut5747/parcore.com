Play a modpack.

Three steps with a launcher. No files to move by hand.

  1. Get a launcher

    The CurseForge App or the Modrinth App, depending on where the pack is listed.

  2. Install the pack

    Search for it inside the launcher and press Install. It sets up the loader and the Minecraft version the pack needs.

  3. Give it memory

    Big packs need more RAM than vanilla. Raise it in the launcher settings; the pack page usually says how much.
