Install a world.

Four steps on Java Edition. Pick your computer.

  1. Right-click the .zip and pick Extract All.Double-click the .zip.Right-click the .zip and pick Extract Here. Open the folder you get: if level.dat is inside, that folder is the world. If you only see another folder, that one is.

  2. Press Win + R, paste this path and press Enter.In Finder, press Shift + Cmd + G, paste this path and press Return.In Files, press Ctrl + L, paste this path and press Enter. Then drag the world folder in.

  3. The version is on the world's card. In the Minecraft Launcher, open Installations, then New installation, and pick it. Parkour, puzzle and minigame maps run on commands that often break in a newer release.

  4. Opening an older world in a newer game upgrades it for good. When Minecraft asks, pick Create Backup and Load. The copy goes to .minecraft/backups.

World questions.

My world doesn't show up in the list.

The folder in saves has to hold level.dat directly. Open the folder you moved: if all you see is one more folder, move that inner folder into saves instead.

The download is a .rar, not a .zip.

Windows 11 opens .rar files on its own. On older Windows use 7-Zip, on a Mac The Unarchiver, on Linux your archive manager. The folder inside works the same way.

It says "Incompatible version" or won't open.

The world was saved in a newer version than your game. Install that version from the Launcher's Installations tab and open it there.

What does "Schematic" on a card mean?

That download is a build, not a world. Paste it into your own world with WorldEdit or Litematica instead of putting it in saves.

Can I play these with friends?

For people on your network, open the world and use Open to LAN in the pause menu. For anyone else, run it on a server: put the world folder next to the server and set level-name in server.properties to the folder's name.

Do these work on Bedrock?

They are Java worlds. Some creators also publish a Bedrock version, like Mosslorn, Stonehill Castle and Zaxestas: check the download page.
