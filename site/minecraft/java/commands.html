Ready-made commands that work in vanilla, no mods needed. Copy one into chat; the long ones go in a command block. Click a name to see it whole.

Where to paste.

Commands only work with cheats on. Turn them on when you create the world, or in an open one: Esc, Open to LAN, Allow Commands: On, then Start LAN World.

Chat

  • Press T, or / to open chat with the slash already typed.
  • Paste the command and press Enter.
  • Chat takes up to 256 characters. Anything longer is cut off and fails.

Command block

  • Get one with the command below, place it and right-click it.
  • Paste the command, then power the block with a button or lever, or set it to Always Active.
  • Holds up to 32,500 characters, so every command on this page fits.
/give @p command_block

Target selectors.

The @ part of a command decides who it hits. Swap it to change the target.

@p
The nearest player. On your own, that is you.
@s
Whoever runs the command. In chat, that is you.
@a
Every player in the world.
@r
One random player.
@e
Every entity: players, mobs, items and more.
@n
The nearest entity of any kind.
[type=zombie]
Only that kind of mob.
[limit=1,sort=nearest]
Just the closest one.
[distance=..10]
Only within 10 blocks.
[name=Steve]
Only things with that name.
[type=!player]
Everything except players.
@e[type=wolf,sort=nearest,limit=1]
Mixed together: the closest wolf. Immortal Wolf uses this.
