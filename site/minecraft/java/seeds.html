Load a seed.

Three steps on Java Edition.

  1. Create a new world

    Singleplayer, then Create New World.

  2. Paste the seed

    Open the World tab and paste the number into Seed for the World Generator.

  3. Match the version

    Play the release the seed was found on. An update that changes world generation can move the terrain.

Seed questions.

Do these seeds work on Bedrock?

They are Java seeds. Since 1.18, Java and Bedrock make mostly the same terrain from the same seed, but villages, mansions and other structures are placed differently, so the spawns shown here will not match on Bedrock.

How do I get to the coordinates on a card?

Press F3 to see where you are. With cheats on, type /tp @s X ~ Z with the card's numbers to go straight there.

How do I find the seed of a world I already have?

Type /seed in chat. In singleplayer it works with cheats off.

Why does my world look different from the screenshots?

Check the version first. Big world generation updates, like 1.18, move terrain for every seed. Smaller updates usually leave it alone.
