Add a data pack.

Keep the download zipped. Minecraft reads the .zip as it is.

  1. Open the pack list

    Create New World, go to the More tab and press Data Packs.

  2. Drop the zip in

    Drag the .zip onto the window, then click it to move it from Available to Selected.

  3. Create the world

    Press Done, then Create. Terrain packs like Terralith shape the world from the first chunk.

  1. Open the world folder

    Singleplayer, select the world, Edit, then Open World Folder.

  2. Drop the zip in

    Put the .zip in the datapacks folder inside it.

  3. Load it

    Join the world and type /reload. Terrain packs only change land you haven't explored yet.

  1. Find the world folder

    It's named after level-name in server.properties, usually world.

  2. Upload the zip

    Put the .zip in world/datapacks with your host's file manager or FTP.

  3. Reload

    Run /reload from the console or as an op. Players don't install anything.

Pack commands.

Run and control packs without leaving the game. Swap in your own file name.

Tap Copy, paste into chat. Only /trigger works with cheats off
  • /datapack list
  • /datapack list enabled
  • /reload
  • /datapack disable "file/Terralith.zip"
  • /datapack enable "file/Terralith.zip" last
  • /datapack enable "file/Terralith.zip" first
  • /function custom_nether_portals:config
  • /trigger TimberToggle

Before you play.

The rules every pack follows, in one screen.

Running packs

Cheats or op
Every /datapack command needs them. Singleplayer: Open to LAN, Allow Commands.
Load order
Lower in /datapack list wins when two packs change the same thing.
What /reload misses
New biomes, dimensions and terrain only apply after you leave and rejoin.

Your world

One world at a time
Each world has its own datapacks folder. New worlds start without them.
Back up first
Copy the world before adding terrain or structure packs. Generated chunks can't be undone.
Removing a pack
Structures it built and items it gave out stay. Only new behaviour stops.

Versions

Version warnings
"Made for an older version" warns you, it doesn't block the pack.
Big updates
Terrain packs usually break across them. Wait for the pack's own update.
Experiments
Mojang's experimental packs can only be switched on when creating a world.

Servers & fixes

Players install nothing
The pack runs on the server. Joining players need no files.
Two-zip packs
Packs with new models also ship a resource pack. Push it with resource-pack in server.properties.
Nothing happens?
Turn on the output log in the launcher settings. Broken files are named there on load.

Make your own.

A data pack is folders of JSON and command files. These do the hard part.

Good to know.

Data pack or mod: what's the difference?

Data packs run on plain vanilla. No Fabric, no Forge, no launcher, and players joining a server install nothing. Mods can add whole new code and blocks; data packs reshape what the game already has: terrain, structures, loot, recipes and mob behaviour.

Do they work on Bedrock?

No. Data packs are Java Edition only. Bedrock has its own add-ons (behaviour packs), and they aren't interchangeable.

Can I add a terrain pack to an old world?

Yes, but it only changes chunks you haven't loaded yet, so there will be a hard edge where old land meets new. For packs like Terralith or Tectonic, a fresh world looks far better.

My pack doesn't show up. Why?

Open the zip: pack.mcmeta must sit at the top, not inside another folder. A zip downloaded from GitHub's green button is often nested one level too deep. Also check the pack supports your Minecraft version.

Do data packs work on Realms?

Yes. Add them to a singleplayer world, then upload that world to your Realm.
