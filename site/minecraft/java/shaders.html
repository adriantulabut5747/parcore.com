Install a shader.

Java needs a shader loader first. Pick one, then add packs.

Iris

  • Runs with Sodium, so frame rates are usually higher.
  • One installer sets up Iris and Sodium together.
  • All 18 Modrinth shaders on this page list Iris support.
Get Iris

OptiFine

  • Works on its own, without a mod loader.
  • Adds zoom, connected textures and more video settings.
  • Slower than Iris and Sodium in most worlds.
Get OptiFine
  1. Install the loader

    Run the Iris installer, or the OptiFine installer, and start the game with that profile.

  2. Add the shader

    Options, Video Settings, Shader Packs, then Open Shader Pack Folder. Drop the .zip in. Keep it zipped.

  3. Turn it on

    Pick the shader in the same list and press Apply. Lower the shader settings there if the frame rate drops.
