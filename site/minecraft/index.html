      Ask the Piglin.

      PiglinThe questions worth asking. Yours isn't here? Drop it in the box. Gold optional.

      Which edition is this for?

      Java Edition. Every /give, /summon or /tellraw a tool makes uses Java syntax, and the seeds are Java seeds. Bedrock places structures differently, so a seed won’t match there.

      How do I install a world?

      Open Worlds and scroll to Install a world. It walks you through it step by step, from the download to the world list, on Windows, Mac and Linux.

      How do I use a command?

      Press Copy, open chat in game with T, paste and press Enter. Cheats must be on, or you need operator on a server. Chat takes 256 characters, so longer ones go in a command block.

      Which version does the Seed Map follow?

      World generation up to Java 1.21.4. Newer versions are only listed once their seeds have been checked in game.
