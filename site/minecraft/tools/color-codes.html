Colours

    Formats

      A colour code switches the formats off, so put the colour first: &c&l is bold red, &l&c is plain red.

      • § codes work in signs, books, item names and server messages. You can't type them in normal chat.
      • Hex colours (&#ff8800) need Java 1.16+ and a server plugin. Vanilla only knows the 16 colours.
      • Bedrock has the same 16 colours plus some of its own, and no underline or strikethrough.
