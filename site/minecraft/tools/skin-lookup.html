The head and the UUID of Notch, ready to paste.

Player head

/give @p minecraft:player_head[minecraft:profile={name:"Notch"}]
One head, given to the nearest player

The head is tied to the name. If the player changes skin, the head shows the new one the next time the world loads.

UUID

  • With dashes069a79f4-44e9-4726-a5be-fca90e38aaf5
  • No dashes069a79f444e94726a5befca90e38aaf5
  • Int array[I;110787060,1156138790,-1514210135,238594805]

NBT stores a player's UUID as this int array from 1.16 on, so commands that match one by UUID need it, for example @e[nbt={UUID:[I;…]}].
